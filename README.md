# 株式会社ムラセコーポレイト ウェブサイト

GitHub Pages 公開用のファイル一式です（通常のHTML・開いた瞬間に表示されます）。

## 構成
- index.html（TOP）
- business.html（運送事業） / support.html（お片付けサポート） / about.html（ムラセコーポレイトとは）
- vehicles.html（保有車両） / recruit.html（採用情報） / faq.html（よくある質問）
- company.html（会社案内） / blog.html（ブログ） / contact.html（お問い合わせ）
- assets/logo-white.png（ロゴ）
- .nojekyll（GitHub Pages 用の設定ファイル・削除しないでください）

## 公開手順
1. GitHub で新しいリポジトリを作成（Public）
2. このフォルダの中身をすべて、構成そのままでリポジトリ直下にアップロード
   （「Add file → Upload files」にフォルダごとドラッグ）
3. Settings → Pages → Source「Deploy from a branch」、Branch「main」「/(root)」→ Save
4. 数分後、https://ユーザー名.github.io/リポジトリ名/ で公開されます

## 公開前の確認事項
- お問い合わせフォームは送信機能が未接続です（Formspree などの連携が必要）
- 写真は外部（cloudfront.net / unsplash.com）から読み込んでいます
- メールアドレス、許可番号、プライバシーポリシー文面は要確認
